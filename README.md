# gitika-bose.github.io

Personal website — [gitika-bose.github.io](https://gitika-bose.github.io/).

Plain static HTML/CSS, no build step. GitHub Pages serves the `master` branch root directly.

```
index.html      # home: about, projects, writing
blog/           # blog posts (one HTML file per post)
styles.css      # shared styles (light/dark via prefers-color-scheme)
```

To add a blog post: copy an existing file in `blog/`, edit the content, and add a card to the Writing section in `index.html`.
